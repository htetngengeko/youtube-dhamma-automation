# youtube-dhamma-automation
An automated, end-to-end backend pipeline designed to generate, assemble, and publish mindfulness and Dhamma teaching videos to YouTube. Orchestrates AI-driven content creation, integrating text generation, voice synthesis, programmatic media rendering, and automated distribution.
